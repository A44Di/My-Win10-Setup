# How to Add and Customize Themes in Flow Launcher (Windows)

## Method 1: Using Pre-installed Themes

Flow Launcher comes with several great built-in themes (both Light and Dark mode options). Here’s how to switch between them:

1. **Open Flow Launcher**: Press your hotkey (usually `Alt + Space`).
2. **Open Settings**: Type `settings` and press **Enter**, or right-click the Flow Launcher icon in the Windows system tray (bottom right corner of your screen) and select **Settings**.
3. **Go to Appearance**: In the Settings window, click on the **Appearance** tab on the left sidebar.
4. **Select a Theme**: Under the "Theme" dropdown menu, you will see a list of pre-installed themes. Click on any theme to instantly preview and apply it.

---

## Method 2: Installing Custom Themes

If you want a completely unique look, you can install custom themes created by the community. Flow Launcher uses `.xaml` files for themes.

### Step 1: Download a Custom Theme

1. You can find custom Flow Launcher themes on GitHub or community forums (like the official Flow Launcher Discord).
2. Download the `.xaml` theme file to your computer.

### Step 2: Locate the Themes Folder

1. Open Flow Launcher (`Alt + Space`).
2. Type `settings` and hit **Enter** to open the Settings menu.
3. Go to the **Appearance** tab.
4. Scroll down slightly and click the button that says **Open Theme Folder**.
   _(Alternatively, you can open File Explorer and navigate directly to: `%APPDATA%\FlowLauncher\Themes`)_

### Step 3: Add Your Custom Theme

1. Drag and drop (or copy/paste) the downloaded `.xaml` theme file into the **Themes** folder you just opened.
2. Close the File Explorer window.

### Step 4: Apply the Custom Theme

1. Go back to the Flow Launcher **Settings > Appearance** tab.
2. Click the **Theme** dropdown menu.
3. Your newly added custom theme should now appear in the list. Select it to apply the new look!
   _(Note: If it doesn't appear immediately, completely exit Flow Launcher from the system tray and restart it)._

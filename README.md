My personal Windows 10 post-installation setup repository! 
Reinstalling Windows can be a tedious process, especially when setting up a fresh development environment. This repository contains the scripts, configurations, and tweaks I use to automate my Windows 10 setup, debloat the system, and install my essential tools for Web & Python development in one go.

## ✨ Features

* **⚡ Automated Software Installation:** Quickly installs essential apps, browsers, and developer tools using [Winget] / [Chocolatey].
* **🧹 System Optimization & Debloat:** Removes unnecessary built-in Windows telemetry and bloatware to keep the system fast and clean.
* **👨‍💻 Developer Ready:** Pre-configures environments for Web Development and Python out of the box.
* **📝 Knowledge Management:** Sets up my preferred digital brain tools (Obsidian, Logseq, Notion).
* **🎨 UI/UX Tweaks:** Adjusts taskbar, explorer, and system settings for maximum productivity.
